# Figures

Generated by `tools/fig_outcomes.py`, which reads the committed result tables at run
time. No number is typed into the figure script, so a figure cannot drift from the
numbers in `docs/OUTCOMES.md`.

```bash
python tools/fig_outcomes.py     # needs matplotlib only
```

## fig_outcomes — what the extended phase established

| panel | shows | source table |
|---|---|---|
| **A** | per-domain Spearman ρ for our head against SaProtΔG and ESM3ΔG, 15 held-out domains | `E3_sota_benchmark/per_domain_*.csv` |
| **B** | our correlation against the agreement between two independent assays, on matched variants | `E2_domainome_external/noise_ceiling_matched_E2.csv` |
| **C** | the specificity axis, its domain-agnostic baseline, and the observed-profile control | `E4_specificity_independent/metrics_E4.json` |
| **D** | the leakage audit | constants stated in `docs/preregistration/E3.md` Part 6.1 |

Design follows the conventions used for the frozen run's D1 figures: Nature two-column
width (183 mm), Okabe-Ito colour-vision-safe palette, sans-serif at 6–7 pt, vector PDF
plus a 600 dpi PNG, and every panel states its n.

**Panel A is the one to read first.** The grey connector makes each domain one row, so
the spread of ESM3ΔG (0.460–0.892) against ours (0.754–0.934) is visible directly —
that consistency gap matters more than the median, because B3's confident calls depend
on the head behaving similarly across domains rather than on a good average.

**Panel C carries the pre-registered control.** The shaded band is everything smaller
than 44 measurements can resolve. All three points sit inside it, *including the
observed phage-display profile* — the quantity the model is trained to predict. A
predictor of X cannot beat X, so the failure is the compositional representation, not
the regression.
