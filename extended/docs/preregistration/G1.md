# G1 — The rules, written down before we look

*(Drafted 28 Sep 2026. Awaiting sign-off. Nothing has been run: no trinucleotide context has been
tabulated, no null has been drawn, and no depletion statistic has been computed.)*

## What this file is for

On 22 September the frozen run reported that observed SH3 cancer variants are **depleted of
predicted fold-breaking substitutions**: 5.93 % destabilising against 9.18 % expected, p ≤ 0.001.
B6 said plainly what that test could not do:

> "mutational context was not modelled, and a trinucleotide-aware null is needed before claiming
> selection."

G1 is that test. It asks **one** question:

> **Does the depletion survive when the background is matched to the mutational process, rather than
> assumed uniform over single-nucleotide-reachable substitutions?**

This is the last of the four standing objections still open, and the only frozen claim with no
independent support. Everything below — the null, the arms, the threshold, and what each possible
outcome licenses — is fixed **now**, before any context is counted. The file is committed to git
first; only then is the notebook written.

Once committed, this file is never edited. If something must change, a dated amendment is added and
the original plan's results are still reported.

---

## Part 1 — Why B6's null is not enough

B6 drew random substitutions from the same domains, restricted to those reachable by a single base
change, and weighted every reachable substitution equally. That controls for **which domains** and
for **the genetic code**, and for nothing else.

It does not control for the fact that mutation is not uniform across the genome. C>T at CpG is
roughly an order of magnitude more likely than most other changes; every tumour type carries its own
mix of processes. If the substitutions that happen to be *common* are also the ones that happen to be
*mild*, a uniform null will report depletion where there is no selection at all.

The two candidate explanations B6 named — weak purifying selection, or mutational bias — are
distinguished by exactly one thing: whether the null knows the sequence context each mutation arose
in. That is what G1 supplies.

### The null population

Every **SNV-reachable missense substitution** in the 310 atlas domains, each carrying a GRCh38
coordinate from the same dbNSFP subset and therefore a trinucleotide context. This is the same pool
B6 sampled from; G1 changes only the weights.

The null pool is built by the same tool and subject to the same reference-base assertion. Its size is
counted and reported **before** any weight is applied.

## Part 3 — The three arms

Each arm draws, from the null pool, the same number of substitutions as the observed set, matched by
domain, with 10,000 draws. The arms differ in **one thing: the weight** on each candidate.

| Arm | Weight on a candidate substitution | Verdict? | What it tests |
|---|---|---|---|
| **1 — MAIN** | **the observed atlas 96-channel spectrum**, divided by the context opportunity in the domain pool | **yes** | the answer |
| 2 | COSMIC **SBS1 + SBS5** (clock-like, active in essentially every tissue), equal mixture | no — robustness | does the verdict depend on the spectrum being taken from our own variants? |
| 3 | **uniform** — B6's null, reimplemented | **no — control** | does this code reproduce 9.18 %? |

### Arm 3 is not optional

**Arm 3 must reproduce B6's expected rate of 9.18 % to within Monte-Carlo error.** If it does not,
G1's implementation differs from B6's in some way that is not the trinucleotide weighting, and
**arms 1 and 2 are not interpretable.** In that case the run stops and the discrepancy is
investigated before any verdict is issued. This is the same role E4's re-run of C4's cross-validation
played: without it, everything downstream is worthless.

### Why arm 1 is the main arm

Taking the spectrum from the atlas's own variants makes the null reproduce the observed mutational
process **exactly, by construction**. Whatever mixture of signatures is active across the tumour
types the atlas aggregates, arm 1 inherits it without having to estimate it. Any depletion that
survives arm 1 therefore cannot be an artefact of which mutations are likely.

The cost is that the spectrum is estimated from the same variants whose damage is being tested. That
is acceptable here because the two are marginals on different axes — the spectrum is a distribution
over 96 sequence contexts, the test statistic is a fraction destabilising — but it is a real
limitation and Part 5 states it as one. Arm 2 exists precisely because arm 1 carries it: SBS1+SBS5
are fixed externally and estimated from nothing in this project.

### Opportunity normalisation

A signature gives P(mutation | context), not P(mutation | position). The weight on a candidate is the
signature's probability for its 96-channel, and candidates are drawn in proportion to that, so
contexts that are abundant in SH3 domains contribute in proportion to both their abundance and their
mutability. The context opportunity counts across the domain pool are reported.

## Part 4 — The decision rule, fixed now

### Test statistic

The **fraction of the observed set called destabilising** (`fold_lo ≥ 1`), against the distribution
of the same fraction over 10,000 domain-matched, context-weighted draws.

### Threshold

**One-sided p < 0.025**, observed below null. One primary question, one arm carrying the verdict; the
threshold matches E1's convention for this project rather than the looser 0.05.

Arms 2 and 3 are reported with their p-values and effect sizes but carry no verdict of their own.

### The three possible outcomes, and what each licenses

Written before the result exists, so that none of them can be argued for afterwards.

| Outcome | Reading | Effect on the thesis |
|---|---|---|
| **Survives** — p < 0.025 **and** the gap retains most of its size | the depletion is not explained by mutational context | **Objection 2 closes.** B6's claim gets its independent support and can be stated as evidence consistent with purifying selection |
| **Vanishes** — p ≥ 0.025 | the depletion is consistent with mutational bias alone | **The frozen claim must be withdrawn** from the manuscript's claims table and reported as not surviving a context-aware null. This is a real possible outcome and is not a failure of G1 |
| **Shrinks but survives** — p < 0.025, gap much reduced | context explains part of it | Both numbers reported. The claim stands in weakened form, with the size of the reduction stated in the abstract, not only in the discussion |

The third row is the one most likely to be fudged, so the rule is explicit: **the effect size is
reported alongside the p-value in every case, and a surviving p with a collapsed effect is written up
as a weakened claim, not as a confirmation.**

### Minimum n

Fewer than **3,000** observed variants with both a coordinate and a prediction → numbers are shown,
**no verdict**, and G1 reports that the coordinate recovery was insufficient. (6,456 are already in
hand, so this floor is not expected to bind; it is stated so that it cannot be chosen later.)

## Part 5 — Power, stated in advance

**G1 is not E1.** E1's germline arm failed on 35 variants and its Q1 arm had 21 pathogenic; G1 has
6,456. The contrast is worth stating precisely, because "underpowered" was the honest verdict on the
last attempt at this objection and it does not carry over.

Approximating the draw distribution as binomial at B6's null rate of 9.18 %:

| n | SD of the drawn fraction | Smallest gap detectable at one-sided 0.025 | B6's observed 3.25-point gap is |
|---|---|---|---|
| **6,456** | 0.36 pp | **0.70 pp** | **9.0 SD** |
| 5,000 | 0.41 pp | 0.80 pp | 8.0 SD |
| 3,000 (the floor) | 0.53 pp | 1.03 pp | 6.2 SD |

So at the n we have, **the test can see a gap roughly a fifth the size of the one B6 reported.** A
null result from G1 will therefore be informative rather than ambiguous: it will mean the depletion
genuinely shrank under a context-aware null, not that the test could not have seen it.

This is an approximation — the real draw is weighted, domain-matched and without replacement, so the
true SD will differ somewhat. The exact Monte-Carlo SD is reported from the 10,000 draws themselves,
and **if it exceeds the binomial approximation by more than a factor of two, the power claim above is
restated with the empirical value** rather than left standing.

No post-hoc power calculation. The numbers above were computed from n and the null rate alone,
before any observed fraction was recomputed.

## Part 6 — Known weaknesses, admitted in advance

- **Arm 1's spectrum is estimated from the variants being tested.** Stated in Part 3. Arm 2 is the
  answer to it, and if arms 1 and 2 disagree, that disagreement is the finding and is reported as
  such rather than resolved in favour of whichever is more convenient.

- **6.2 % of the atlas is excluded** (428 variants: 314 ambiguous, 114 absent from dbNSFP). The
  exclusion is on coordinate recoverability, which plausibly correlates with genes that have many
  transcripts. Whether the excluded set differs in destabilising rate **will be computed and
  reported**, verdict or not. It is not a condition on the verdict, because the rule for that would
  have to be invented after seeing it.

- **A context-matched null removes mutational bias, not every non-selective process.** Replication
  timing, chromatin state and sequencing coverage all vary across the genome and none is modelled. A
  surviving depletion is evidence *consistent with* purifying selection, not a demonstration of it,
  and the manuscript must keep that wording.

- **The atlas aggregates many tumour types.** Arm 1 absorbs the mixture by construction; arm 2 assumes
  clock-like processes dominate, which is a genuine simplification and is why arm 2 does not carry the
  verdict.

- **Some of the 96 channels will be sparse.** SH3 domains are a small target. Channels with too few
  observed variants make the arm-1 spectrum noisy; the per-channel counts are reported so a reader can
  see where that bites.

- **The same model limits as B1/B3/B6 apply** — compression of severe effects, weakest on glycine and
  proline, isolated-domain scoring. G1 inherits them and changes none of them.

- **Depletion is not the only possible signal.** G1 tests one direction, declared in advance
  (observed below null), because that is what B6 reported. An enrichment would be reported as
  observed but carries no verdict under this file.

## Part 8 — Attestation

Required by this project's convention that counting is allowed but looking at the relationship is
not.

**Confirmed as of drafting.** The work done before this file existed was: the coordinate join
(`tools/g1_coordinates.py`), which reads `variant_id`, `gene`, `pos_protein`, `wt_aa`, `mut_aa`,
`uniprot` and `mutation_cds` from the atlas and chr/pos/ref/alt from dbNSFP, and a reference-base
verification against GRCh38. **No prediction column was loaded.** `pred_ddG_fold` and `fold_lo` were
never read, no trinucleotide context has been extracted for any variant, no 96-channel spectrum has
been tabulated, and no fraction destabilising has been recomputed on the 6,456.

The power table in Part 5 was computed from n and B6's published null rate of 9.18 %, both of which
were already public in `RESULTS_B6.md`. It used no G1 data.

One caveat, stated rather than glossed: B6's observed rate of 5.93 % on all 6,884 variants is
published and known. G1's observed rate is on the 6,456 subset and has not been computed, but it will
obviously be close to 5.93 %. The guarantee here is that the **comparison against a context-aware
null** has not been examined, not that the observed rate is a surprise.
