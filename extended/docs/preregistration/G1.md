# G1 — The rules, written down before we look

*(Drafted 28 Sep 2026. Awaiting sign-off. Nothing has been run: no trinucleotide context has been
tabulated, no null has been drawn, and no depletion statistic has been computed.)*

## What this file is for

On 22 September the frozen run reported that observed SH3 cancer variants are **depleted of
predicted fold-breaking substitutions**: 5.93 % destabilising against 9.18 % expected, p ≤ 0.001.
B6 said plainly what that test could not do:

> "mutational context was not modelled, and a trinucleotide-aware null is needed before claiming
> selection."

G1 is that test. It asks **one** question:

> **Does the depletion survive when the background is matched to the mutational process, rather than
> assumed uniform over single-nucleotide-reachable substitutions?**

This is the last of the four standing objections still open, and the only frozen claim with no
independent support. Everything below — the null, the arms, the threshold, and what each possible
outcome licenses — is fixed **now**, before any context is counted. The file is committed to git
first; only then is the notebook written.

Once committed, this file is never edited. If something must change, a dated amendment is added and
the original plan's results are still reported.

---

## Part 1 — Why B6's null is not enough

B6 drew random substitutions from the same domains, restricted to those reachable by a single base
change, and weighted every reachable substitution equally. That controls for **which domains** and
for **the genetic code**, and for nothing else.

It does not control for the fact that mutation is not uniform across the genome. C>T at CpG is
roughly an order of magnitude more likely than most other changes; every tumour type carries its own
mix of processes. If the substitutions that happen to be *common* are also the ones that happen to be
*mild*, a uniform null will report depletion where there is no selection at all.

The two candidate explanations B6 named — weak purifying selection, or mutational bias — are
distinguished by exactly one thing: whether the null knows the sequence context each mutation arose
in. That is what G1 supplies.

## Part 3 — The three arms

Each arm draws, from the null pool, the same number of substitutions as the observed set, matched by
domain, with 10,000 draws. The arms differ in **one thing: the weight** on each candidate.

| Arm | Weight on a candidate substitution | Verdict? | What it tests |
|---|---|---|---|
| **1 — MAIN** | **the observed atlas 96-channel spectrum**, divided by the context opportunity in the domain pool | **yes** | the answer |
| 2 | COSMIC **SBS1 + SBS5** (clock-like, active in essentially every tissue), equal mixture | no — robustness | does the verdict depend on the spectrum being taken from our own variants? |
| 3 | **uniform** — B6's null, reimplemented | **no — control** | does this code reproduce 9.18 %? |

### Arm 3 is not optional

**Arm 3 must reproduce B6's expected rate of 9.18 % to within Monte-Carlo error.** If it does not,
G1's implementation differs from B6's in some way that is not the trinucleotide weighting, and
**arms 1 and 2 are not interpretable.** In that case the run stops and the discrepancy is
investigated before any verdict is issued. This is the same role E4's re-run of C4's cross-validation
played: without it, everything downstream is worthless.

### Why arm 1 is the main arm

Taking the spectrum from the atlas's own variants makes the null reproduce the observed mutational
process **exactly, by construction**. Whatever mixture of signatures is active across the tumour
types the atlas aggregates, arm 1 inherits it without having to estimate it. Any depletion that
survives arm 1 therefore cannot be an artefact of which mutations are likely.

The cost is that the spectrum is estimated from the same variants whose damage is being tested. That
is acceptable here because the two are marginals on different axes — the spectrum is a distribution
over 96 sequence contexts, the test statistic is a fraction destabilising — but it is a real
limitation and Part 5 states it as one. Arm 2 exists precisely because arm 1 carries it: SBS1+SBS5
are fixed externally and estimated from nothing in this project.

### Opportunity normalisation

A signature gives P(mutation | context), not P(mutation | position). The weight on a candidate is the
signature's probability for its 96-channel, and candidates are drawn in proportion to that, so
contexts that are abundant in SH3 domains contribute in proportion to both their abundance and their
mutability. The context opportunity counts across the domain pool are reported.

## Part 4 — The decision rule, fixed now

### Test statistic

The **fraction of the observed set called destabilising** (`fold_lo ≥ 1`), against the distribution
of the same fraction over 10,000 domain-matched, context-weighted draws.

### Threshold

**One-sided p < 0.025**, observed below null. One primary question, one arm carrying the verdict; the
threshold matches E1's convention for this project rather than the looser 0.05.

Arms 2 and 3 are reported with their p-values and effect sizes but carry no verdict of their own.

### The three possible outcomes, and what each licenses

Written before the result exists, so that none of them can be argued for afterwards.

| Outcome | Reading | Effect on the thesis |
|---|---|---|
| **Survives** — p < 0.025 **and** the gap retains most of its size | the depletion is not explained by mutational context | **Objection 2 closes.** B6's claim gets its independent support and can be stated as evidence consistent with purifying selection |
| **Vanishes** — p ≥ 0.025 | the depletion is consistent with mutational bias alone | **The frozen claim must be withdrawn** from the manuscript's claims table and reported as not surviving a context-aware null. This is a real possible outcome and is not a failure of G1 |
| **Shrinks but survives** — p < 0.025, gap much reduced | context explains part of it | Both numbers reported. The claim stands in weakened form, with the size of the reduction stated in the abstract, not only in the discussion |

The third row is the one most likely to be fudged, so the rule is explicit: **the effect size is
reported alongside the p-value in every case, and a surviving p with a collapsed effect is written up
as a weakened claim, not as a confirmation.**

### Minimum n

Fewer than **3,000** observed variants with both a coordinate and a prediction → numbers are shown,
**no verdict**, and G1 reports that the coordinate recovery was insufficient. (6,456 are already in
hand, so this floor is not expected to bind; it is stated so that it cannot be chosen later.)

## Part 5 — Power, stated in advance

**G1 is not E1.** E1's germline arm failed on 35 variants and its Q1 arm had 21 pathogenic; G1 has
6,456. The contrast is worth stating precisely, because "underpowered" was the honest verdict on the
last attempt at this objection and it does not carry over.

Approximating the draw distribution as binomial at B6's null rate of 9.18 %:

| n | SD of the drawn fraction | Smallest gap detectable at one-sided 0.025 | B6's observed 3.25-point gap is |
|---|---|---|---|
| **6,456** | 0.36 pp | **0.70 pp** | **9.0 SD** |
| 5,000 | 0.41 pp | 0.80 pp | 8.0 SD |
| 3,000 (the floor) | 0.53 pp | 1.03 pp | 6.2 SD |

So at the n we have, **the test can see a gap roughly a fifth the size of the one B6 reported.** A
null result from G1 will therefore be informative rather than ambiguous: it will mean the depletion
genuinely shrank under a context-aware null, not that the test could not have seen it.

This is an approximation — the real draw is weighted, domain-matched and without replacement, so the
true SD will differ somewhat. The exact Monte-Carlo SD is reported from the 10,000 draws themselves,
and **if it exceeds the binomial approximation by more than a factor of two, the power claim above is
restated with the empirical value** rather than left standing.

No post-hoc power calculation. The numbers above were computed from n and the null rate alone,
before any observed fraction was recomputed.

## Part 6 — Known weaknesses, admitted in advance

- **Arm 1's spectrum is estimated from the variants being tested.** Stated in Part 3. Arm 2 is the
  answer to it, and if arms 1 and 2 disagree, that disagreement is the finding and is reported as
  such rather than resolved in favour of whichever is more convenient.

- **6.2 % of the atlas is excluded** (428 variants: 314 ambiguous, 114 absent from dbNSFP). The
  exclusion is on coordinate recoverability, which plausibly correlates with genes that have many
  transcripts. Whether the excluded set differs in destabilising rate **will be computed and
  reported**, verdict or not. It is not a condition on the verdict, because the rule for that would
  have to be invented after seeing it.

- **A context-matched null removes mutational bias, not every non-selective process.** Replication
  timing, chromatin state and sequencing coverage all vary across the genome and none is modelled. A
  surviving depletion is evidence *consistent with* purifying selection, not a demonstration of it,
  and the manuscript must keep that wording.

- **The atlas aggregates many tumour types.** Arm 1 absorbs the mixture by construction; arm 2 assumes
  clock-like processes dominate, which is a genuine simplification and is why arm 2 does not carry the
  verdict.

- **Some of the 96 channels will be sparse.** SH3 domains are a small target. Channels with too few
  observed variants make the arm-1 spectrum noisy; the per-channel counts are reported so a reader can
  see where that bites.

- **The same model limits as B1/B3/B6 apply** — compression of severe effects, weakest on glycine and
  proline, isolated-domain scoring. G1 inherits them and changes none of them.

- **Depletion is not the only possible signal.** G1 tests one direction, declared in advance
  (observed below null), because that is what B6 reported. An enrichment would be reported as
  observed but carries no verdict under this file.

## Part 9 — Decisions taken, 28 Sep 2026

Three points raised on review. This section is the operative plan; where it differs from Parts 3–5,
**this section governs**. Still nothing has been run.

### 9.1 Two notebooks, not two arms in one

Arms 1 and 2 become **separate notebooks**, `G1a_observed_spectrum` and `G1b_cosmic_spectrum`.

Everything except the spectrum is **shared code, not a shared intention**: the eligible variant set,
the domain-specific opportunity counts, the B6 predictions, the draw procedure, the test statistic and
the seed all live in `tools/g1_core.py`, which both notebooks import. Two notebooks that merely *look*
the same would leave any difference in the result ambiguous between the spectrum and an
implementation slip.

**The uniform control (arm 3) runs in both.** It takes no spectrum, so both notebooks must return the
*same* uniform null rate, to the digit, from the same seed. That makes the control do two jobs at
once: it checks this implementation against B6's published 9.18 %, and it proves the shared machinery
really is shared. A divergence there stops both notebooks before any verdict, exactly as Part 3 said.

A third step, `tools/g1_compare.py`, reads both metrics files and reports the two null rates, the two
observed-vs-null results, and the difference between them. **That comparison is the deliverable** —
whether the conclusion depends on which spectrum is assumed.

### 9.2 α = 0.025 has its own rationale, and it is not E1's

Part 4 justified α = 0.025 as "E1's convention for this project". **That is withdrawn.** E1 used
0.025 because it asked two questions and split 0.05 between them; G1 asks one, so nothing carries
over and the number needed its own reason.

It has one. **G1's test is one-sided, and α = 0.025 one-sided is the conventional analogue of a
two-sided 0.05** — the standard significance level, not a stricter one, expressed for a test with a
direction declared in advance. The direction was declared in Part 6 and is B6's.

### 9.3 Which spectrum is primary may be chosen later — but the *rule* is fixed now

Choosing the primary analysis after seeing which one gives the smaller p is the precise thing a
pre-registration exists to prevent. So the decision may be deferred, and the **cost of deferring is
paid in advance**:

| | Primary named **before either notebook is run** | Primary **not named** before the run |
|---|---|---|
| Structure | one primary, one sensitivity analysis | **two co-primary tests** |
| Threshold | primary at **α = 0.025**; the sensitivity arm is reported with its p-value and effect size but **carries no verdict** | **α = 0.0125 each** (Bonferroni, family-wise 0.025) |
| Verdict | the named arm's | **both must clear 0.0125** for the depletion to be called surviving; one clearing and one not is reported as *spectrum-dependent*, which is itself the finding |

Deferring is cheap and the numbers say so:

| α | smallest gap detectable at n = 6,456 |
|---|---|
| one-sided 0.025 | 0.70 pp |
| **one-sided 0.0125** | **0.81 pp** |

B6's gap is **3.25 pp**, about 9 SD. The adjustment costs roughly a tenth of a percentage point of
sensitivity, so nothing of consequence is lost by leaving the choice open.

**If a primary is named, it must be named in writing in this file, with its reason, before either
notebook is executed.** If this file still has no such note when the notebooks run, the co-primary
column applies automatically and the report says so.

### 9.4 How "which is better" is to be judged

Fixed now, because it is the judgement most exposed to hindsight.

The observed spectrum is estimated from the variants being tested, so it is **not independent of the
test set** — Part 6 already admits this and it is the reason arm 2 exists. But the COSMIC mixture is
not automatically the safer choice either: SBS1+SBS5 assume clock-like processes dominate, which
across an atlas aggregating many tumour types is a real assumption and may fit worse.

So the comparison is decided on **biological fit and robustness, never on which p-value is smaller**:

1. **Fit.** How well does each spectrum reproduce the observed 96-channel distribution? Reported as
   cosine similarity between the assumed spectrum and the observed one. The observed spectrum wins
   this by construction; the number that matters is *how badly* COSMIC loses, because a close fit
   means the non-independence is buying little.
2. **Robustness.** Do the two notebooks agree on the verdict? Agreement makes the conclusion
   spectrum-independent and the non-independence moot. Disagreement is reported as the finding, and
   neither is promoted.
3. **Channel support.** Per-channel observed counts are reported. If the observed spectrum rests on
   sparse channels, that weakens arm 1 specifically, and it is visible rather than argued.

**No arm is promoted to primary after results are seen.** Under the co-primary column that is
structurally impossible, which is the other reason deferring is safe.

## Part 10 — Amendment, 28 Sep 2026: what the null draws *from*

Still nothing run. This fixes a definition that Parts 2–3 left implicit and that the notebooks cannot
be written without.

### The unit of sampling was never stated

Part 2 called the null pool "every SNV-reachable missense substitution". That is ambiguous, and the
two readings are not the same set:

| Unit | What one item is | Size |
|---|---|---|
| **amino-acid substitution** | a (position, wt→mut) pair reachable by *some* single base change | **150,040** (B6) |
| **base change** | a specific (chromosome, position, ref→alt) mutation | **152,852** (dbNSFP, in domain) |

They differ because one amino-acid change can be reachable by more than one base change, and each
such base change has its **own trinucleotide context**. A context-weighted null is meaningless at the
amino-acid level — context is a property of the mutation, not of the substitution it produces.

**G1 draws base changes.** That is the unit mutation acts on, and it is the only unit at which a
96-channel spectrum can be applied.

### That changes what the control must show

The two pools are within 1.9 % of each other in size, which does **not** mean multiplicity is rare —
the two enumerations are built differently and a coincidence of totals says nothing about the overlap.
Among the 6,672 atlas variants matched on a UniProt-aligned transcript, **1,170 (17.5 %) carried more
than one candidate coordinate**, so multiplicity is common enough to matter and its true rate in the
pool is not yet known.

So the uniform control splits in two, and **both run in both notebooks**:

| Control | Uniform over | Reproduces |
|---|---|---|
| **3a** | amino-acid substitutions | **B6's 9.18 %** — the reproduction check, as Part 3 requires |
| **3b** | base changes | the mutation-level uniform baseline |

**3a is the arm that must reproduce 9.18 %**, and Part 3's stop condition attaches to it alone. If 3a
reproduces B6 and 3b does not equal it, that difference is not an error — it is the effect of
reachability multiplicity, isolated from sequence context, and it is reported as its own number.

The three quantities then separate cleanly, which is the point:

```
3a  uniform over substitutions   ── B6's null
3b  uniform over base changes    ── + reachability multiplicity
1/2 spectrum-weighted            ── + trinucleotide context
```

Each step's contribution to the null rate is reported. The **observed set is compared against 1 and
2**, exactly as Part 4 says; 3a and 3b carry no verdict and exist to say where any change came from.

### Reported before any weight is applied

- pool size under each unit, and the multiplicity distribution (how many base changes reach each
  amino-acid substitution);
- how many of B6's 150,040 substitutions receive at least one coordinate, since any that receive none
  are silently absent from the base-change pool and that is an exclusion like any other.

## Part 11 — Amendment, 28 Sep 2026: "retains most of its size" gets a number

Still nothing run.

Part 4's middle outcome — *survives, but the gap is much reduced* — was written in
prose: "p < 0.025 **and** the gap retains most of its size". Writing the code made it
obvious that prose is not a rule. Some threshold will decide which of two verdicts gets
printed, and if it is not fixed here it will be fixed by whoever reads the output.

**A surviving depletion is reported as `survives` when the gap is at least half of
B6's, that is ≥ 1.63 pp, and as `shrinks_but_survives` below that.** Half is a round
number chosen for being round; it is not derived from anything, and it is written down
now precisely because any number chosen after seeing the gap would be worth less than a
round one chosen before.

Both labels mean the depletion cleared its threshold. The distinction governs **how it
is written up**, per Part 4: `shrinks_but_survives` is reported in the abstract as a
weakened claim with the size of the reduction stated, not as a confirmation.

The rule is implemented in `tools/g1_core.py:verdict()` so that the label comes out of
the same code in both notebooks and cannot be assigned by hand.

## Part 12 — Amendment, 28 Sep 2026: B6's null pool contains substitutions that cannot happen

The 3a control fired, and investigating it as Part 3 requires found that the control's
premise, not its implementation, is wrong. Nothing about the spectrum arms has been run.

### What the control found

3a returned 0.0776 against B6's published 0.0918. Two defects in the pool were fixed first
(X1's in-domain parquet was filtered on a different transcript than the atlas numbers
against; matching the UniProt accession admits rows from a different isoform, 23.7 % of
them). Coverage of B6's reachable set went 56.6 % → 77.1 %, domains with no coverage at all
15 → 0, and the gap did **not** close.

It cannot close, and the reason is arithmetic.

### B6's reachability is amino-acid-level; mutation is codon-level

`snv_reachable` in B6 asks whether a substitution is reachable by one base change from
**some** codon of the wild-type residue. What can actually occur at a position is whatever
is reachable from **the codon that is there**. These differ, and the difference is large:

| | |
|---|---|
| B6 reachable substitutions | 150,040 |
| of those, reachable from the codon actually present | **115,742 (77.1 %)** |

The shortfall is a property of the amino-acid pair, not of our data coverage:

| pair | observed | genetic code predicts | |
|---|---|---|---|
| S→W | 0.07 | 0.17 | only `TCG` reaches `TGG` |
| L→W | 0.14 | 0.17 | only `TTG` reaches `TGG` |
| S→T | 1.00 | 1.00 | every Ser codon reaches Thr |
| L→V | 1.00 | 1.00 | every Leu codon reaches Val |

Across the 150 pairs with n ≥ 100: **r = +0.955** against the pure genetic-code prediction,
mean absolute deviation 0.05, and **no pair where the code says unreachable and we found
any**. The residuals go the way codon usage predicts — V→M is 0.555 observed against 0.25
unweighted because `GTG` is the dominant Val codon and is the one that reaches `ATG`.

So the 22.9 % is the genetic code, not a gap in dbNSFP.

### It matters, because what B6 over-counts is more damaging

| null rate, fraction destabilising | |
|---|---|
| B6 published, amino-acid-pair reachability | **0.09232** |
| reachable from the codon actually present | **0.08635** |
| the excluded remainder | 0.11246 |
| observed cancer variants | 0.05929 |

**B6's expected rate is inflated by 0.60 pp by substitutions that cannot arise at those
positions**, and the depletion it reported shrinks from 3.25 pp to about 2.7 pp before any
trinucleotide weighting is applied at all. That is a correction to a frozen number, arrived
at by a control written before any of it was known.

### What changes here

**The reproduction check moves from the draw to the pool, and is strengthened, not dropped.**

Our handling of B6 reproduces its published rate **exactly** — 0.09232 over B6's own
reachable set, against 0.09232 published. That is what the control existed to establish:
that any difference downstream is the null's definition and not our arithmetic. It is now
asserted on that number, where it is exact, instead of on a draw from a pool B6 never used.

| arm | draws from | expected | role |
|---|---|---|---|
| **reproduction** | B6's own reachable set, no draw | **0.09232**, asserted to 5 × 10⁻⁴ | proves our B6 handling |
| **3a** | codon-reachable substitutions | ≈ 0.0864 | the corrected uniform baseline |
| 3b | codon-reachable base changes | reported | + reachability multiplicity |
| 1 / 2 | spectrum-weighted base changes | reported | + trinucleotide context |

Part 3's stop condition now attaches to the **reproduction** row. Part 10's decomposition
gains a step at the top:

```
B6 published        0.0923  -- amino-acid-pair reachability
3a                  ~0.0864 -- codon reachability          (-0.60 pp, THIS amendment)
3b                          -- + reachability multiplicity
1/2                         -- + trinucleotide context
```

### What this does not do

It does **not** rescue or weaken the verdict in advance. Part 4's three outcomes and Part
9.3's thresholds are untouched, and the observed rate is unchanged at 0.0596. The effect is
that the gap G1 tests against is smaller than B6 reported, which makes a *surviving*
depletion a stronger result and a *vanishing* one more likely — the change cuts against the
claim the project would prefer, which is the only reason it is safe to make after seeing
the number that prompted it.

The 22.9 % restriction is also now a stated limitation in its own right: G1's null is
codon-aware where B6's was not, and the two are therefore not the same test. Both rates are
reported side by side wherever the depletion is quoted.

### Consequence for B6 and the manuscript

`RESULTS_B6.md` and the manuscript quote 9.18 % as the expected rate. That figure is not
wrong as B6 defined it, and B6 is frozen and is not re-run. But it answers a question nobody
asked — what fraction of *amino-acid-level* reachable substitutions is destabilising — and
the manuscript should quote the codon-aware 8.6 % alongside it, with this amendment cited.
`ANALYSIS_G1.md` carries the full statement once the arms have run.
