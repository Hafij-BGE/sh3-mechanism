# E4 — The rules, written down before we look

Independent test of C4's specificity axis against dissociation constants measured by a different
group, by a different method.

Written 27 September 2026, before the notebook exists.

---

## What this file is for

C4 built a specificity axis and failed its own pre-registered rule: median centred r = +0.288, better
than the family-average profile on only 55 of 115 domains, `validated: false`. That failure was
measured against the same phage-display data the model was trained on. E4 asks whether the axis
predicts **binding affinities measured independently**.

**The expected answer is no**, and that is the point. A second, independent failure is a stronger
negative result than one internal failure. "The specificity axis does not predict measured SH3
affinities" is a cleaner claim than "our axis did not clear our own threshold".

This file exists so that the negative result cannot be waved away as a badly chosen test, and so that
an unexpected *positive* result is labelled post-hoc — because C4's rule has already been declared and
already returned false.

---

## Part 1 — What the model actually predicts

This was checked in the C4 notebook before any of the rules below were written, and it decides the
whole design.

C4 reads 154 phage-display PWMs, each 14 positions × 20 amino acids, and **collapses each one to a
single 20-dimensional vector** — the information-content-weighted average across positions:

```python
ic = np.log2(20) + (P * np.log2(P)).sum(0)     # information content per position
profile = (P * ic).sum(1) / ic.sum()           # one 20-vector per domain
```

So the axis is a statement about **amino-acid composition**, not about position. It can say "this
domain prefers proline, tryptophan and leucine". It cannot say "position 4 must be a basic residue".
The model is ESM-2 650M mean-pooled embedding of the domain sequence → Ridge → that 20-vector in
centred-log-ratio space.

**Consequence, stated before any score is computed:** E4 can only ask whether compositional preference
predicts affinity. Two peptides with the same amino-acid composition in a different order are
indistinguishable to this model, by construction. That is a limit on what a *positive* result here
would mean, not an excuse for a negative one.

## Part 2 — The data, pinned

| | |
|---|---|
| Measured affinities | `input/external/binding/kazemein_jasemi_2024_TableS6_Kd.csv` — 45 Kd values, 17 domains, 0.2–125 µM |
| Peptide sequences | `input/external/binding/kazemein_jasemi_2024_TableS2_peptides.csv` — 12 peptides, extracted from the same supplementary PDF, every one validated against its published residue coordinates |
| C4's inputs | `input/datasets/SH3_PWM.zip`, `input/datasets/HumanSH3TableS2.xlsx` on the frozen run's Drive folder, MD5-verified |
| C4's recorded output | `results/C4_specificity_axis/{pwm_profiles.csv,specificity_cv.csv,specificity_decision.json}` |

Ten peptides are SOS1-derived proline-rich motifs; RP1 and RP2 are reference peptides. Nine of the
twelve carry at least one measurement. **RP1 (SOS1 1147–1158) is a sub-sequence of P3 (1146–1171)**,
so those two are not independent; they are treated as distinct peptides and a sensitivity check drops
RP1.

## Part 3 — How a peptide is scored — fixed now

For domain *d* with predicted profile **ŷ**_d (the Ridge output, in centred-log-ratio space) and
peptide *p* with amino-acid frequency vector **f**_p:

```
S(d, p) = Σ_a  f_p(a) · ŷ_d(a)
```

the mean predicted log-preference per residue. Frequencies, not counts, so peptide length does not
enter. No window, no alignment — the profile has no positional structure to align to.

**Direction, fixed now:** a better compositional match should bind more tightly, so we predict
**S negatively correlated with log₁₀ Kd**. A positive correlation of any size is a failure, not a
success with the sign flipped.

Three profiles are scored the same way:

| | Profile used | What it tests |
|---|---|---|
| **model** | C4's prediction for that domain | the thing under test |
| **average** | the training-set mean profile | domain-agnostic baseline — varies by peptide only |
| **observed** | the domain's own phage-display profile | the control (Part 6) |

## Part 4 — Leakage: which prediction is used for which domain

12 of the 17 measured domains have a PWM in C4's training set. Using the final model on them would be
scoring the training data.

- **In C4's training set (12 domains, 37 measurements)** — ABL2, ARHGAP12, BIN1, CRK-1, GRB2-1,
  GRB2-2, ITSN1-1, ITSN1-5, NCK1-2, RIMBP3B-1, SH3PXD2A-1, SRC. E4 re-runs C4's cross-validation
  (same ≥ 40 % identity single-linkage clustering, same per-fold alpha selection) and uses the
  **leave-cluster-out** prediction: the fold in which that domain's whole cluster of relatives was
  held out.
- **Never in C4's training set (4 domains, 7 measurements)** — ABI1, DLG2, NCK1-3, SORBS1-1. The final
  model applies with no leakage. Domain sequences come from the atlas (`wt_domain_seq`); all four map
  unambiguously.
- **Excluded (1 domain, 1 measurement)** — ARHGEF30 is not in our 235-gene UniProt SH3 table, so we
  have no domain sequence for it. Declared now, before any score exists: **44 measurements, 16
  domains** enter the analysis.

Where a domain name maps to several C4 entries (isoform-specific variants: SRC has two), their
profiles are averaged — the same rule C4 used for domains with two PWMs.

## Part 5 — The experiments

### Experiment 1 — MAIN

**Does the predicted profile rank peptides correctly within a domain?**

Within-domain-centred correlation over the 12 training-set domains, leave-cluster-out predictions:
subtract each domain's own mean from both `S` and `log₁₀ Kd`, pool, and take Pearson *r* with
`df = n − k − 1 = 37 − 12 − 1 = 24`. This removes every domain-level effect, so what remains is
specificity — which peptide *this* domain prefers — and nothing else.

**Verdict requires both:** *r* < 0 with p < 0.025, **and** |*r*| larger than the same statistic
computed with the average profile. The second condition is the C4 rule restated: a model with no
domain-specific information cannot beat a domain-agnostic baseline.

### Experiment 2 — the assumption-free version

Per-domain Spearman ρ between `S` and `log₁₀ Kd`, for domains with **≥ 3** measurements — 8 of them
(ABL2 3, ARHGAP12 4, BIN1 3, GRB2-1 5, GRB2-2 5, ITSN1-1 3, ITSN1-5 3, SH3PXD2A-1 3). Aggregated by a
two-sided sign test on the direction, plus the median ρ with a bootstrap CI.

**Verdict requires** the sign test p < 0.025 and the median ρ's CI to exclude 0 — the same shape of
rule as C4's own.

### Experiment 3 — pooled, reported without a verdict

Spearman ρ over all 44 measurements with no domain centring. Reported for completeness and
**explicitly given no verdict**, because peptide identity dominates it: the reference peptides bind
almost everything tightly, so a pooled correlation can look respectable while carrying no
domain-specific information at all.

### Experiment 4 — the never-trained-on domains, counts only

The 4 domains and 7 measurements C4 never saw. Reported; **no verdict at any n**, declared now.

### Experiment 5 — sensitivity

Experiment 1 recomputed (a) dropping RP1, which is nested inside P3, and (b) using Spearman on
within-domain ranks instead of Pearson on centred values. Reported beside the main number; neither can
overturn it.

## Part 6 — The control that decides what a failure means

**Every experiment is repeated with the domain's own observed phage-display profile in place of the
prediction.** Without this, a negative result is uninterpretable: it could mean C4's model is wrong, or
it could mean that compositional profiles from phage display simply do not predict solution affinities
for these peptides.

The reading is fixed now:

| observed profile | model | Conclusion |
|---|---|---|
| fails | fails | **The measurement, not the model.** The honest claim is "phage-display compositional preferences do not predict these affinities" — E4 cannot convict C4 specifically |
| passes | fails | **The model.** The approach works on this data and C4's prediction of it does not — the strongest form of the negative result |
| — | passes | **Post-hoc success.** C4's rule already returned false; reported as post-hoc, and no rewiring claim is revived on this basis |

## Part 7 — What counts as a yes, and what the power actually is

- **α = 0.025** — 0.05 across the two experiments carrying a verdict.
- **Minimum size:** Experiment 1 needs ≥ 20 measurements across ≥ 8 domains; Experiment 2 needs ≥ 8
  domains. Both are met exactly as counted above. If a filter drops either below its minimum, that
  experiment returns "too few" and no verdict.

**Stated before any result exists:**

- Experiment 1 at df = 24 and α = 0.025 can only detect **|r| ≥ 0.44**. A weak-but-real compositional
  signal would return a null here.
- Experiment 2 has 8 domains, so the two-sided sign test reaches 0.025 **only at 8/8**. 7 of 8 in the
  right direction gives p ≈ 0.07 and therefore no verdict. This is a coarse test and is reported as
  one.

So a null in E4 means "no effect large enough for 44 measurements to see", never "no effect". The
negative result this program expects is worth having because it is *independent*, not because it is
precise.

## Part 8 — Known weaknesses, admitted in advance

1. **The peptides are nearly all proline-rich SOS1 fragments.** The compositional range is narrow,
   which works against any compositional model. A reviewer may fairly say the test is hard; the reply
   is that the model is what it is and these are the measurements that exist.
2. **Nine peptides, 16 domains, 44 measurements.** Small.
3. **Not a like-for-like PWM test.** Phage display measures enrichment from a library; this paper
   measures Kd for specific peptides. Agreement is expected to be loose even for a correct model.
4. **Kd values are used as published**, with no reanalysis of the underlying binding curves and no
   uncertainty attached, because none is tabulated.
5. **RP1 ⊂ P3.** Handled by Experiment 5(a), not by exclusion.
